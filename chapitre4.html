Chapitre 4: Les Conditions

Objectif

Maîtriser les structures conditionnelles pour que ton programme puisse prendre des décisions intelligentes.

Partie Théorique

Qu'est-ce qu'une condition ?

Une condition permet à ton programme de prendre des décisions. C'est comme dans la vie réelle :

  • SI il pleut, ALORS je prends mon parapluie
  • SI j'ai faim, ALORS je mange, SINON je continue à jouer

En Python, on utilise les mots-clés if (si), elif (sinon si), et else (sinon).

Structure if / else

if condition:
    # Code exécuté si la condition est vraie
else:
    # Code exécuté si la condition est fausse

Exemple :

age = 12
if age >= 12:
    print("Tu peux aller au collège")
else:
    print("Tu es encore à l'école primaire")

Important : L'indentation !

En Python, l'indentation (les espaces au début de la ligne) est OBLIGATOIRE. Elle montre quel code appartient à la condition.

# ✅ CORRECT
if age > 10:
    print("Plus de 10 ans")  # 4 espaces d'indentation
    print("Tu grandis !")

# ❌ ERREUR
if age > 10:
print("Plus de 10 ans")  # Manque l'indentation !

Les opérateurs de comparaison

Opérateur Signification Exemple Résultat
== Égal à 5 == 5 True
!= Différent de 5 != 3 True
< Plus petit que 3 < 5 True
> Plus grand que 5 > 3 True
<= Plus petit ou égal 3 <= 3 True
>= Plus grand ou égal 5 >= 5 True

Attention : Pour comparer, on utilise == (deux signes égal), pas = (qui sert à affecter une valeur) !

Structure if / elif / else

Quand tu as plusieurs conditions à vérifier, utilise elif (sinon si) :

note = 15

if note >= 16:
    print("Excellent !")
elif note >= 14:
    print("Très bien !")
elif note >= 12:
    print("Bien")
elif note >= 10:
    print("Assez bien")
else:
    print("Tu peux mieux faire")

Les opérateurs logiques

Pour combiner plusieurs conditions :

  • and (et) : Les DEUX conditions doivent être vraies
  • or (ou) : AU MOINS UNE condition doit être vraie
  • not (non) : Inverse la condition
# AND - Les deux conditions doivent être vraies
age = 12
a_carte = True
if age >= 12 and a_carte:
    print("Tu peux entrer au cinéma")

# OR - Au moins une condition doit être vraie
jour = "samedi"
if jour == "samedi" or jour == "dimanche":
    print("C'est le week-end !")

# NOT - Inverse le résultat
est_fatigue = False
if not est_fatigue:
    print("On peut jouer !")

Exercice 1 : Vérificateur d'âge

Énoncé : Demande l'âge de l'utilisateur et affiche un message selon son âge :

  • Moins de 12 ans : "Tu es à l'école primaire"
  • 12-14 ans : "Tu es au collège"
  • 15-17 ans : "Tu es au lycée"
  • 18 ans ou plus : "Tu es adulte"

Indice: Utilise if, elif et else pour tester les différentes tranches d'âge.

age = int(input("Quel âge as-tu ? "))

if age < 12:
    print("Tu es à l'école primaire")
elif age <= 14:
    print("Tu es au collège")
elif age <= 17:
    print("Tu es au lycée")
else:
    print("Tu es adulte")

Exercice 2 : Calculateur de réduction

Énoncé : Un magasin applique des réductions selon l'âge :

  • Moins de 12 ans : 50% de réduction
  • 12-17 ans : 30% de réduction
  • 18-64 ans : pas de réduction
  • 65 ans et plus : 40% de réduction

Demande l'âge et le prix de base, puis affiche le prix final après réduction.

Indice: Utilise des conditions pour déterminer le pourcentage de réduction, puis calcule : prix_final = prix * (1 - reduction)

age = int(input("Quel âge as-tu ? "))
prix = float(input("Quel est le prix de base ? "))

if age < 12:
    reduction = 0.50
    print("Réduction enfant : 50%")
elif age <= 17:
    reduction = 0.30
    print("Réduction jeune : 30%")
elif age <= 64:
    reduction = 0
    print("Pas de réduction")
else:
    reduction = 0.40
    print("Réduction senior : 40%")

prix_final = prix * (1 - reduction)
print("Prix final :", prix_final, "€")

Exercice 3 : Accès à une attraction

Énoncé : Pour monter dans une attraction de parc d'attractions, il faut :

  • Avoir AU MOINS 12 ans ET mesurer AU MOINS 1,40m
  • OU être accompagné d'un adulte

Demande l'âge, la taille et si la personne est accompagnée. Affiche si elle peut monter ou non.

Indice: Utilise les opérateurs and et or. Structure : if (condition1 and condition2) or condition3:

age = int(input("Quel âge as-tu ? "))
taille = float(input("Quelle est ta taille en m ? "))
accompagne = input("Es-tu accompagné d'un adulte ? (oui/non) ")

if (age >= 12 and taille >= 1.40) or accompagne == "oui":
    print("✅ Tu peux monter dans l'attraction !")
else:
    print("❌ Désolé, tu ne peux pas monter")

Travail Pratique : Jeu du "Pierre, Papier, Ciseaux"

Projet : Crée un jeu de Pierre-Papier-Ciseaux contre l'ordinateur !

Règles :

  • Pierre bat Ciseaux
  • Ciseaux bat Papier
  • Papier bat Pierre

Instructions :

  1. Demande au joueur de choisir : pierre, papier ou ciseaux
  2. L'ordinateur choisit aléatoirement (utilise le code fourni)
  3. Compare les choix et affiche qui a gagné
  4. Gère tous les cas possibles (égalité, victoire, défaite)

Code pour le choix aléatoire de l'ordinateur :

import random
choix_ordi = random.choice(["pierre", "papier", "ciseaux"])

Défi bonus : Affiche le score sur plusieurs manches !

Indice: Utilise des conditions imbriquées. D'abord vérifie l'égalité, puis teste toutes les combinaisons gagnantes pour le joueur.

import random

print("=" * 40)
print("  JEU PIERRE - PAPIER - CISEAUX")
print("=" * 40)
print()

# Choix du joueur
choix_joueur = input("Choisis pierre, papier ou ciseaux : ").lower()

# Choix de l'ordinateur
choix_ordi = random.choice(["pierre", "papier", "ciseaux"])
print("L'ordinateur a choisi :", choix_ordi)
print()

# Déterminer le gagnant
if choix_joueur == choix_ordi:
    print("🤝 Égalité !")
elif (choix_joueur == "pierre" and choix_ordi == "ciseaux") or \
     (choix_joueur == "ciseaux" and choix_ordi == "papier") or \
     (choix_joueur == "papier" and choix_ordi == "pierre"):
    print("🎉 Tu as gagné !")
else:
    print("😢 L'ordinateur a gagné !")

print()
print("=" * 40)
