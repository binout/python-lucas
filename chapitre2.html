Chapitre 2: Variables et Types de Données

Objectif

Maîtriser les variables, comprendre les différents types de données et apprendre à les manipuler en Python.

Partie Théorique

Qu'est-ce qu'une variable ?

Une variable est comme une boîte étiquetée dans laquelle tu peux ranger une information. Cette boîte a :

  • Un nom (l'étiquette sur la boîte) : par exemple age
  • Une valeur (ce qu'il y a dans la boîte) : par exemple 12
  • Un type (le type d'objet dans la boîte) : par exemple un nombre

En Python, on crée une variable avec le signe = (qu'on appelle "opérateur d'affectation") :

nom_variable = valeur

Les types de données en Python

1. String (str) - Chaînes de caractères

Un string (ou "chaîne de caractères") est du texte. On le met toujours entre guillemets.

prenom = "Lucas"
ville = 'Paris'  # Les guillemets simples fonctionnent aussi
message = "J'aime Python !"

2. Integer (int) - Nombres entiers

Un integer est un nombre entier (sans virgule). Pas besoin de guillemets !

age = 12
nombre_eleves = 25
score = -5  # Les nombres négatifs sont aussi des entiers

3. Float - Nombres décimaux

Un float est un nombre avec une virgule (en Python, on utilise un point).

taille = 1.52  # en mètres
temperature = 23.5  # en degrés
prix = 9.99

4. Boolean (bool) - Vrai ou Faux

Un boolean ne peut avoir que deux valeurs : True (Vrai) ou False (Faux).

est_majeur = False
aime_python = True

Règles pour nommer les variables

  • ✅ Utilise des lettres, des chiffres et le underscore (_) : mon_age, score_joueur1
  • ✅ Commence toujours par une lettre ou underscore : _variable, nom
  • ❌ Ne commence jamais par un chiffre : 1nom est interdit
  • ❌ Pas d'espaces : utilise underscore à la place : mon_nom et non mon nom
  • ❌ Pas de caractères spéciaux (@, !, %, etc.)
  • 💡 Utilise des noms descriptifs : age est mieux que a

Afficher le type d'une variable

Pour connaître le type d'une variable, utilise la fonction type() :

age = 12
print(type(age))  # Affiche: <class 'int'>

nom = "Lucas"
print(type(nom))  # Affiche: <class 'str'>

Exemples pratiques

prenom = "Lucas"
age = 12
taille = 1.52
est_en_classe = True

print("Prénom :", prenom)
print("Âge :", age)
print("Taille :", taille, "m")
print("En classe ?", est_en_classe)

Exercice 1 : Créer tes premières variables

Énoncé : Crée 3 variables pour stocker :

  • Ton film préféré (string)
  • Ton nombre de bonbons (integer)
  • Ton poids en kg (float)

Ensuite, affiche chaque variable avec un message descriptif.

Indice: Utilise des noms de variables clairs. N'oublie pas les guillemets pour le film. Affiche avec print().

film_prefere = "Spider-Man"
nombre_bonbons = 15

print("Mon film préféré est :", film_prefere)

Exercice 2 : Tous les types de données

Énoncé : Crée 4 variables de types différents :

  • Un string : ton animal préféré
  • Un integer : ton année de naissance
  • Un float : la note de ton dernier contrôle (sur 20)
  • Un boolean : si tu aimes les mathématiques (True ou False)

Affiche le type de chaque variable avec type().

Indice: Utilise print(type(variable)) pour afficher le type. N'oublie pas : True et False commencent par une majuscule !

animal_prefere = "chat"
annee_naissance = 2013
note = 15.5
aime_maths = True

print("Animal :", animal_prefere, "- Type :", type(animal_prefere))
print("Année :", annee_naissance, "- Type :", type(annee_naissance))
print("Note :", note, "- Type :", type(note))
print("Aime maths :", aime_maths, "- Type :", type(aime_maths))

Exercice 3 : Modifier une variable

Énoncé : Les variables peuvent changer de valeur ! Crée une variable score avec la valeur 0. Affiche-la. Ensuite, change sa valeur à 100 et affiche-la à nouveau.

Indice: Tu peux réaffecter une nouvelle valeur à une variable en utilisant à nouveau le signe =

score = 0
print("Score initial :", score)

score = 100
print("Nouveau score :", score)

Travail Pratique : Fiche de personnage de jeu vidéo

Projet : Crée la fiche d'un personnage de jeu vidéo avec les variables suivantes :

  • nom_personnage : le nom de ton personnage (string)
  • classe : guerrier, mage, archer, etc. (string)
  • niveau : le niveau du personnage (integer)
  • points_vie : les HP du personnage (integer)
  • force_attaque : la puissance d'attaque (float)
  • est_vivant : True si vivant, False sinon (boolean)

Affiche toutes ces informations de manière claire et organisée, comme une vraie fiche de personnage !

Défi bonus : Ajoute 3 variables supplémentaires de ton choix (armure, agilité, mana, etc.)

Indice: Organise ton affichage avec des titres et des séparateurs. Utilise plusieurs print() pour structurer la fiche.

# Création du personnage
nom_personnage = "Aragorn"
classe = "Guerrier"
niveau = 15
points_vie = 250
force_attaque = 87.5
est_vivant = True

# Bonus
armure = 120
agilite = 45.3
or = 1500

# Affichage de la fiche
print("=" * 40)
print("     FICHE DE PERSONNAGE")
print("=" * 40)
print()
print("Nom :", nom_personnage)
print("Classe :", classe)
print("Niveau :", niveau)
print()
print("--- Statistiques ---")
print("Points de vie :", points_vie, "HP")
print("Force d'attaque :", force_attaque)
print("Armure :", armure)
print("Agilité :", agilite)
print()
print("Statut :", "Vivant" if est_vivant else "Mort")
print("Or :", or, "pièces")
print()
print("=" * 40)
