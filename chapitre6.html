Chapitre 6: Les Listes

Objectif

Maîtriser les listes pour stocker et manipuler des collections de données de manière efficace.

Partie Théorique

Qu'est-ce qu'une liste ?

Une liste est une structure de données qui permet de stocker plusieurs valeurs dans une seule variable. C'est comme une boîte divisée en compartiments numérotés.

Au lieu d'écrire :

fruit1 = "pomme"
fruit2 = "banane"
fruit3 = "cerise"

On peut écrire :

fruits = ["pomme", "banane", "cerise"]

Créer une liste

Une liste se crée avec des crochets [] et les éléments sont séparés par des virgules.

# Liste de strings
fruits = ["pomme", "banane", "cerise"]

# Liste de nombres
nombres = [1, 2, 3, 4, 5]

# Liste mixte (différents types)
mixte = ["Lucas", 12, 1.52, True]

# Liste vide
ma_liste = []

Accéder aux éléments - Les index

Chaque élément d'une liste a un index (position). Attention : Les index commencent à 0 !

Élément "pomme" "banane" "cerise"
Index 0 1 2 
fruits = ["pomme", "banane", "cerise"]

print(fruits[0])   # pomme (premier élément)
print(fruits[1])   # banane
print(fruits[2])   # cerise
print(fruits[-1])  # cerise (dernier élément)
print(fruits[-2])  # banane (avant-dernier)

Modifier une liste

Changer un élément :

fruits = ["pomme", "banane", "cerise"]
fruits[1] = "orange"
print(fruits)  # ["pomme", "orange", "cerise"]

Ajouter un élément :

# append() : Ajoute à la fin
fruits.append("kiwi")
print(fruits)  # ["pomme", "orange", "cerise", "kiwi"]

# insert() : Ajoute à un index précis
fruits.insert(1, "fraise")
print(fruits)  # ["pomme", "fraise", "orange", "cerise", "kiwi"]

Supprimer un élément :

# remove() : Supprime par valeur
fruits.remove("orange")

# pop() : Supprime par index (et retourne la valeur)
dernier = fruits.pop()  # Supprime le dernier
print(dernier)  # kiwi

# del : Supprime par index
del fruits[0]  # Supprime "pomme"

Méthodes utiles des listes

Méthode Description Exemple
len(liste) Longueur de la liste len([1,2,3]) → 3
liste.append(x) Ajoute x à la fin fruits.append("kiwi")
liste.remove(x) Supprime x fruits.remove("pomme")
liste.pop() Supprime le dernier élément fruits.pop()
liste.sort() Trie la liste nombres.sort()
liste.reverse() Inverse l'ordre fruits.reverse()
x in liste Vérifie si x est dans la liste "pomme" in fruits

Parcourir une liste avec une boucle

# Méthode 1 : Parcourir les éléments directement
fruits = ["pomme", "banane", "cerise"]
for fruit in fruits:
    print(fruit)

# Méthode 2 : Parcourir avec les index
for i in range(len(fruits)):
    print(f"Index {i} : {fruits[i]}")

Travail Pratique : Gestionnaire de playlist musicale

Projet : Crée un programme de gestion de playlist musicale avec un menu interactif !

Fonctionnalités à implémenter :

  1. Afficher la playlist : Montre toutes les chansons avec leur numéro
  2. Ajouter une chanson : Demande le titre et l'ajoute à la playlist
  3. Supprimer une chanson : Supprime une chanson par son numéro
  4. Nombre de chansons : Affiche le total de chansons
  5. Rechercher une chanson : Vérifie si une chanson est dans la playlist
  6. Quitter : Termine le programme

Le programme doit :

  • Afficher un menu avec les options
  • Utiliser une boucle pour garder le programme actif
  • Utiliser des conditions pour gérer chaque choix

Défi bonus : Ajoute une option pour mélanger aléatoirement la playlist (utilise random.shuffle()) !

Indice: Utilise une boucle while True pour le menu. Chaque option correspond à une condition if/elif. Utilise break pour quitter.

import random

playlist = ["Bohemian Rhapsody", "Imagine", "Billie Jean"]

print("=" * 50)
print("    GESTIONNAIRE DE PLAYLIST")
print("=" * 50)
print()

while True:
    print("\n--- MENU ---")
    print("1. Afficher la playlist")
    print("2. Ajouter une chanson")
    print("3. Supprimer une chanson")
    print("4. Nombre de chansons")
    print("5. Rechercher une chanson")
    print("6. Mélanger la playlist (BONUS)")
    print("7. Quitter")
    print()

    choix = input("Choisis une option (1-7) : ")

    if choix == "1":
        print("\n🎵 PLAYLIST ACTUELLE :")
        if len(playlist) == 0:
            print("La playlist est vide")
        else:
            for i in range(len(playlist)):
                print(f"{i+1}. {playlist[i]}")

    elif choix == "2":
        titre = input("Titre de la chanson à ajouter : ")
        playlist.append(titre)
        print(f"✅ '{titre}' ajoutée !")

    elif choix == "3":
        if len(playlist) == 0:
            print("La playlist est vide")
        else:
            for i in range(len(playlist)):
                print(f"{i+1}. {playlist[i]}")
            num = int(input("Numéro de la chanson à supprimer : "))
            if 1 <= num <= len(playlist):
                supprime = playlist.pop(num - 1)
                print(f"🗑️ '{supprime}' supprimée !")
            else:
                print("❌ Numéro invalide")

    elif choix == "4":
        print(f"📊 Nombre de chansons : {len(playlist)}")

    elif choix == "5":
        recherche = input("Titre à rechercher : ")
        if recherche in playlist:
            position = playlist.index(recherche) + 1
            print(f"✅ Trouvée à la position {position}")
        else:
            print("❌ Chanson non trouvée")

    elif choix == "6":
        random.shuffle(playlist)
        print("🔀 Playlist mélangée !")

    elif choix == "7":
        print("👋 Au revoir !")
        break

    else:
        print("❌ Option invalide")

print("\n" + "=" * 50)
