Chapitre 3: Les Opérations de Base

Objectif

Maîtriser les opérations mathématiques, découvrir comment récupérer des données de l'utilisateur et convertir entre différents types.

Partie Théorique

Les opérateurs arithmétiques

Python peut faire toutes les opérations mathématiques que tu connais. Voici les opérateurs arithmétiques :

Opérateur Nom Exemple Résultat
+ Addition 5 + 3 8
- Soustraction 5 - 3 2
* Multiplication 5 * 3 15
/ Division 10 / 3 3.333...
// Division entière 10 // 3 3
% Modulo (reste) 10 % 3 1
** Puissance 2 ** 3 8

Exemples détaillés

a = 10
b = 3

print(a + b)   # 13 - Addition
print(a - b)   # 7 - Soustraction
print(a * b)   # 30 - Multiplication
print(a / b)   # 3.333... - Division normale (donne toujours un float)
print(a // b)  # 3 - Division entière (partie entière du résultat)
print(a % b)   # 1 - Reste de la division (10 divisé par 3 = 3, reste 1)
print(a ** b)  # 1000 - 10 à la puissance 3

Ordre de priorité des opérations

Python respecte les règles mathématiques. L'ordre de priorité est :

  1. Parenthèses ()
  2. Puissance **
  3. Multiplication/Division *, /, //, %
  4. Addition/Soustraction +, -
resultat = 2 + 3 * 4
print(resultat)  # 14 (et pas 20 !)
# Car 3 * 4 = 12, puis 2 + 12 = 14

resultat2 = (2 + 3) * 4
print(resultat2)  # 20
# Les parenthèses forcent à calculer 2 + 3 d'abord

La fonction input() - Récupérer des données

La fonction input() permet de demander à l'utilisateur de taper quelque chose :

nom = input("Quel est ton nom ? ")
print("Bonjour", nom)

Attention : input() retourne toujours un string (texte) !

Conversion de types

Pour faire des calculs avec des nombres saisis par l'utilisateur, il faut convertir le texte en nombre :

  • int() : convertit en nombre entier
  • float() : convertit en nombre décimal
  • str() : convertit en texte
age_texte = input("Quel âge as-tu ? ")  # Retourne un string
age_nombre = int(age_texte)  # Convertit en integer
annee_prochaine = age_nombre + 1
print("L'année prochaine, tu auras", annee_prochaine, "ans")

On peut aussi tout faire en une ligne :

age = int(input("Quel âge as-tu ? "))
print("L'année prochaine, tu auras", age + 1, "ans")

Exercice 1 : Calculatrice simple

Énoncé : Crée deux variables a = 15 et b = 4. Affiche le résultat de toutes les opérations arithmétiques entre ces deux nombres (addition, soustraction, multiplication, division, division entière, modulo et puissance).

Indice: Crée les deux variables, puis utilise 7 print() avec les 7 opérateurs différents.

a = 15
b = 4

print("Addition :", a + b)
print("Soustraction :", a - b)
print("Multiplication :", a * b)
print("Division :", a / b)
print("Division entière :", a // b)
print("Modulo :", a % b)
print("Puissance :", a ** b)

Exercice 2 : Convertisseur semaines → jours

Énoncé : Demande à l'utilisateur un nombre de semaines et affiche combien cela fait de jours.

Rappel : 1 semaine = 7 jours

Indice: Utilise input() pour récupérer le nombre de semaines, convertis-le en int(), puis multiplie par 7.

semaines = int(input("Combien de semaines veux-tu convertir ? "))
jours = semaines * 7
print(semaines, "semaines =", jours, "jours")

Exercice 3 : Calcul de moyenne

Énoncé : Demande à l'utilisateur 3 notes (peuvent être décimales). Calcule et affiche la moyenne de ces 3 notes.

Indice: Utilise float() pour convertir les notes car elles peuvent être décimales. Moyenne = (note1 + note2 + note3) / 3

note1 = float(input("Note 1 : "))
note2 = float(input("Note 2 : "))
note3 = float(input("Note 3 : "))

moyenne = (note1 + note2 + note3) / 3
print("Ta moyenne est :", moyenne)

Travail Pratique : Convertisseur universel

Projet : Crée un programme de conversion qui propose plusieurs convertisseurs :

  1. Convertisseur d'âge :
    • Demande l'âge en années
    • Affiche l'âge en mois, en semaines et en jours
    • (1 an = 12 mois = 52 semaines = 365 jours)
  2. Convertisseur de température :
    • Demande une température en Celsius
    • Affiche la température en Fahrenheit
    • Formule : F = (C × 9/5) + 32
  3. Convertisseur de monnaie :
    • Demande un montant en euros
    • Affiche la conversion en dollars (1€ = 1.10$) et en livres (1€ = 0.85£)

Défi bonus : Ajoute un 4ème convertisseur de ton choix (distance, vitesse, poids, etc.) !

Indice: Organise ton programme en sections avec des print() pour les titres. Utilise int() ou float() selon le type de donnée nécessaire.
