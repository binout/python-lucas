💻 1. Installer Python sur Mac avec Homebrew

Homebrew est un gestionnaire de paquets pour Mac qui facilite l'installation de Python et d'autres outils de développement.

1 Installer Homebrew (si pas déjà installé)

Ouvre le Terminal (dans Applications > Utilitaires) et tape cette commande :

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

⏱️ L'installation peut prendre quelques minutes. Entre ton mot de passe Mac si demandé.

2 Installer Python avec Homebrew

Une fois Homebrew installé, tape dans le Terminal :

brew install python

Homebrew va télécharger et installer la dernière version de Python.

3 Vérifier l'installation

Tape dans le Terminal :

python3 --version

Tu devrais voir quelque chose comme : Python 3.12.1

✅ Si tu vois le numéro de version, Python est bien installé !
ℹ️ Note :

Sur Mac, utilise toujours python3 (et non python) dans le terminal.

✏️ 2. Installer Visual Studio Code

VS Code est un éditeur de code professionnel et gratuit, parfait pour apprendre Python.

1 Télécharger VS Code

Va sur le site officiel :

⬇️ Télécharger VS Code pour Mac

Choisis la version pour macOS (Apple Silicon ou Intel selon ton Mac).

2 Installer VS Code
  1. Ouvre le fichier .zip téléchargé
  2. Glisse l'application "Visual Studio Code" dans ton dossier Applications
  3. Lance VS Code depuis le dossier Applications
3 Installer l'extension Python
  1. Dans VS Code, clique sur l'icône Extensions (carré avec 4 carrés) dans la barre latérale gauche
  2. Cherche "Python" dans la barre de recherche
  3. Clique sur l'extension "Python" de Microsoft (la première normalement)
  4. Clique sur "Install"
✅ VS Code est prêt pour coder en Python !

Tu as maintenant un environnement professionnel avec coloration syntaxique, autocomplétion et débogage.

💡 Conseil :

VS Code peut sembler complexe au début, mais tu vas vite t'y habituer. C'est l'outil utilisé par les vrais développeurs !

🎯 3. Écrire et exécuter ton premier programme avec VS Code

1 Créer un dossier pour tes projets Python
  1. Crée un dossier "Formation-Python" sur ton Mac (dans Documents par exemple)
  2. Dans VS Code, clique sur "File" > "Open Folder"
  3. Sélectionne ton dossier "Formation-Python"
2 Créer ton premier fichier Python
  1. Dans VS Code, clique sur l'icône "Nouveau fichier" (ou File > New File)
  2. Sauvegarde le fichier (Cmd + S) et nomme-le hello.py
  3. VS Code va détecter que c'est un fichier Python et activer la coloration syntaxique
3 Écrire ton code

Dans le fichier hello.py, écris :

print("Bonjour, le monde !")
print("Je m'appelle Lucas")
print("J'ai 12 ans")

Sauvegarde avec Cmd + S

4 Exécuter ton programme

Tu as plusieurs options :

  • Option 1 (recommandé) : Clique sur le bouton "▶ Run" en haut à droite
  • Option 2 : Clique droit dans l'éditeur > "Run Python File in Terminal"
  • Option 3 : Dans le Terminal intégré de VS Code (View > Terminal), tape : 
    python3 hello.py
✅ Ton programme s'exécute et affiche le résultat dans le Terminal !

Tu devrais voir :

Bonjour, le monde !
Je m'appelle Lucas
J'ai 12 ans
💡 Astuce VS Code :
  • Cmd + S : Sauvegarder
  • Cmd + /: Commenter/décommenter une ligne
  • Ctrl + ` : Ouvrir/fermer le terminal
  • Autocomplétion : Commence à taper et VS Code te propose des suggestions !

📝 4. Comment faire les exercices

1 Lis l'énoncé attentivement

Comprends bien ce qui est demandé avant de commencer à coder.

2 Essaie par toi-même d'abord

N'utilise pas tout de suite les indices ou la solution. Tente de résoudre l'exercice seul, même si tu fais des erreurs !

3 Crée un nouveau fichier Python
  • Nomme-le clairement : chapitre1_exercice1.py
  • Écris ton code dans ce fichier
  • Sauvegarde régulièrement
4 Teste ton code
  • Exécute ton programme (F5 dans IDLE)
  • Vérifie que le résultat correspond à ce qui est demandé
  • Si ça ne fonctionne pas, lis les messages d'erreur
5 Utilise les aides si nécessaire
  • Si tu es bloqué plus de 5-10 minutes, clique sur "💡 Afficher un indice"
  • L'indice te donne une piste sans te donner la réponse complète
  • Si vraiment tu ne trouves pas, regarde "✨ Afficher la solution"
⚠️ Important :

Même si tu regardes la solution, recopie le code à la main au lieu de faire un copier-coller. Tu apprendras beaucoup mieux comme ça !

6 Expérimente !

Une fois l'exercice réussi, modifie le code pour voir ce qui se passe. C'est comme ça qu'on apprend vraiment !

🎯 5. Comment réaliser les travaux pratiques

Les travaux pratiques (TP) sont des petits projets qui combinent plusieurs concepts. Ils sont un peu plus longs que les exercices.

1 Lis tout le TP avant de commencer

Comprends l'objectif global et les fonctionnalités demandées.

2 Décompose en étapes

Ne code pas tout d'un coup ! Avance étape par étape :

  • Commence par la partie la plus simple
  • Teste après chaque fonctionnalité ajoutée
  • Ajoute progressivement les autres parties
3 Exemple : TP Carte de visite (Chapitre 1)

Au lieu de tout écrire d'un coup, fais ça progressivement :

  1. D'abord, affiche juste le titre
  2. Teste → ça marche ? OK, continue
  3. Ajoute ton nom
  4. Teste → ça marche ? OK, continue
  5. Ajoute ton âge, tes passions, etc.
  6. Teste à chaque fois !
✅ Astuce :

Prends ton temps ! Les TP sont là pour t'amuser et créer quelque chose de cool. Tu peux même personnaliser au-delà de ce qui est demandé !

4 Tente les défis bonus !

Chaque TP a un défi bonus. C'est optionnel mais très formateur. N'hésite pas à essayer !

💡 6. Astuces et bonnes pratiques

Quand tu rencontres une erreur

Ne panique pas ! Les erreurs sont normales et font partie de l'apprentissage. Tous les programmeurs en font, même les experts !

Comment lire un message d'erreur :

  1. Regarde la dernière ligne : elle indique le type d'erreur
  2. Regarde le numéro de ligne : elle te dit où est l'erreur
  3. Lis le message : il explique souvent le problème

Erreurs courantes :

  • SyntaxError : Tu as oublié quelque chose (parenthèse, guillemet...)
  • NameError : Tu as mal écrit un nom de variable
  • IndentationError : Problème d'indentation (espaces en début de ligne)

Conseils pour bien coder

  • ✅ Nomme bien tes fichiers : chapitre1_exercice2.py plutôt que test.py
  • ✅ Commente ton code : Utilise # pour expliquer ce que tu fais
  • ✅ Teste souvent : N'écris pas 50 lignes d'un coup, teste régulièrement
  • ✅ Sauvegarde : Utilise Ctrl+S (ou Cmd+S sur Mac) régulièrement
  • ✅ Organise tes fichiers : Crée un dossier "Formation Python" pour tout ranger

Organisation recommandée
