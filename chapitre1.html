Chapitre 1: Découverte de Python

Objectif

Comprendre ce qu'est Python, découvrir comment communiquer avec l'ordinateur et créer tes premiers programmes.

Partie Théorique

Qu'est-ce que Python ?

Python est un langage de programmation créé en 1991 par Guido van Rossum. Un langage de programmation, c'est une façon de communiquer avec un ordinateur en lui donnant des instructions précises.

Imagine que tu veux qu'un robot fasse le ménage dans ta chambre. Tu dois lui expliquer exactement quoi faire : "ramasse les vêtements", "range-les dans l'armoire", etc. C'est la même chose avec Python : tu écris des instructions que l'ordinateur va suivre à la lettre.

Pourquoi Python est-il populaire ?

  • Facile à lire : Le code Python ressemble presque à de l'anglais, ce qui le rend plus simple à comprendre
  • Puissant : On peut créer des jeux vidéo, des applications, des sites web, et même programmer des robots !
  • Très utilisé : Des entreprises comme YouTube, Instagram, Spotify et Netflix utilisent Python

Qu'est-ce qu'un programme ?

Un programme, c'est une suite d'instructions que l'ordinateur exécute dans l'ordre. Chaque ligne de code est une instruction.

La fonction print()

La fonction print() est l'une des fonctions les plus importantes en Python. Elle permet d'afficher du texte à l'écran.

Syntaxe :

print("Ton message ici")

Points importants :

  • Le texte doit être entre guillemets (simples ' ou doubles ")
  • Les parenthèses sont obligatoires
  • Python fait la différence entre majuscules et minuscules : print() fonctionne, mais Print() donnera une erreur !

Premier Programme

Voici le programme traditionnel que tous les programmeurs écrivent en premier :

print("Bonjour, le monde!")

Quand tu exécutes ce programme, l'ordinateur affiche : Bonjour, le monde!

Afficher plusieurs lignes

Tu peux utiliser plusieurs print() pour afficher plusieurs lignes :

print("Ligne 1")
print("Ligne 2")
print("Ligne 3")

Exercice 1 : Mon premier message

Énoncé : Écris un programme qui affiche "Bienvenue dans le monde de Python !" à l'écran.

Indice: Utilise la fonction print() et place ton message entre guillemets.

print("Bienvenue dans le monde de Python !")

Exercice 2 : Présentation personnelle

Énoncé : Écris un programme qui affiche 4 lignes pour te présenter :

  • Ton prénom
  • Ton âge
  • Ta ville
  • Ton sport ou hobby préféré

Indice: Utilise 4 fonctions print(), une pour chaque information.

print("Je m'appelle Lucas")
print("J'ai 12 ans")
print("J'habite à Paris")
print("J'adore le football")

Exercice 3 : Dessin ASCII

Énoncé : Crée un petit dessin avec du texte en utilisant plusieurs print(). Par exemple, dessine un bonhomme sourire ou une maison.

Indice: Utilise des caractères comme *, -, |, o pour créer ton dessin. Chaque ligne du dessin = un print().

# Bonhomme sourire
print("  *****  ")
print(" *     * ")
print("*  o o  *")
print("*   ^   *")
print("* \\_____/ *")
print(" *     * ")
print("  *****  ")
