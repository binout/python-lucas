# Formation Python Débutant Collège 🐍

Formation interactive pour apprendre Python de zéro, destinée aux collégiens (12 ans et +).

## 📚 Contenu de la formation

**6 chapitres progressifs** avec exercices et projets pratiques :

1. **Découverte de Python** - Premiers pas avec `print()` et création d'une carte de visite virtuelle
2. **Variables et Types** - Stockage d'informations et création d'une fiche de personnage
3. **Opérations Mathématiques** - Calculs et création d'un convertisseur universel
4. **Les Conditions** - Prise de décisions et développement du jeu Pierre-Papier-Ciseaux
5. **Les Boucles** - Automatisation et création d'un jeu de devinette
6. **Les Listes** - Collections de données et gestionnaire de playlist musicale

## 🚀 Pour commencer

1. Ouvre `index.html` dans ton navigateur
2. Suis le guide de démarrage pour installer Python et VS Code sur Mac
3. Commence le Chapitre 1 !
